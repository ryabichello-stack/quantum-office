# P1.9 — Clarity test (Selling Website exit)

**Revision:** REV-3.2 · 2026-09-01  
**URL для теста:** https://a.47z.ru/delno/  
**Критерий:** за **5–10 секунд** человек понимает продукт без подсказок.

---

## Кого тестировать

- Минимум **3 человека**, не знакомых с DELNO и не участвовавших в разработке
- Желательно: владелец малого бизнеса, маркетолог, «обычный пользователь»

---

## Протокол (5 минут на человека)

1. Открыть URL на телефоне или ноутбуке **без объяснений**
2. Дать **10 секунд** посмотреть первый экран
3. Задать **4 вопроса** (записать дословно):

| # | Вопрос |
|---|--------|
| 1 | Что это за продукт? |
| 2 | Что он делает для бизнеса? |
| 3 | Где / через что он работает? |
| 4 | Что бы вы нажали, чтобы попробовать? |

4. Не исправлять и не наводить — только фиксировать ответы

---

## Pass / Fail

### ✅ Pass (hero работает)

Ответ близок к:

> «ИИ-сотрудник, который отвечает клиентам — на сайте, по телефону, в мессенджерах; консультирует, записывает, принимает заявки»

### ❌ Fail (hero дорабатывать)

Ответы типа:

- «какая-то AI-платформа»
- «чат-бот для сайта»
- «CRM / автоматизация»
- «не понял / слишком абстрактно»

**Правило:** если **2+ из 3** дают fail-категорию → переделывать hero (P1.1), не закрывать Sprint 3.
