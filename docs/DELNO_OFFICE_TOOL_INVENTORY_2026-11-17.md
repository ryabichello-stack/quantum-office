# DELNO: офисные инструменты и Beget-бэкап — 17.11.2026

Проверены `/srv/beget-full-20261112/backup.tar` (выборка `opt/ava-{calendar,conference,files,mailer}`), текущий `delno-api` и `delno-office`. Секреты и токены не копировались.

| Возможность | Было в Beget | Сейчас в DELNO | Что требуется |
| --- | --- | --- | --- |
| Проверка времени, три альтернативы, создание CalDAV-события | `ava-calendar/{main,caldav_client}.py` | `delno-office/calendar` и `delno-api/adapters/connectors/calendar.py` | Внутренний календарь DELNO как источник истины; внешний провайдер опционален |
| Перенос и отмена внешнего события | Нет API в старом `ava-calendar` | Нет API в новом брокере | Идентификатор внешнего события, update/delete по каждому провайдеру, повторы и статус синхронизации |
| Видеоссылка | `ava-conference`, Telemost | `delno-office/conference`, заявлены также Meet/Zoom/Teams/Jitsi | Доказать собственные права доступа компании; не принимать stub URL за готовую встречу |
| Отдельное письмо с PDF-презентацией | `_send_welcome_presentation_email` в `ava-mailer/main.py` прикладывал файл из серверного пути | `delno-office/mail/office_gateway.py` принимает только текст; `appointments._send` добавляет фразу вместо вложения | Хранить PDF в файлах компании; расширить tenant-scoped SMTP шлюз вложением; проверять `sent` и `attached` |
| Файлы | `ava-files` list/search/fetch/upload/send | `delno-office/files` + tenant path isolation в `tenant_files.py` | Связать выбранный файл компании с шаблоном письма, не использовать общий путь сервера |
| Голосовые инструменты | `quantum-console` регистрировал офисные вызовы и переводы звонков | DELNO `voice_tools.dispatch`, tenant по `CallSession`, разрешённые инструменты по сценарию | Номер звонящего только из сессии, одни действия записи для голоса и мессенджеров |
| Telegram и MAX | Отдельные боты | Есть входящие адаптеры и ID отправителя | Привязка контакта между каналами только после подтверждения; без неё управлять лишь своими записями канала |

Текущий этап в PR: отдельная таблица встреч, API и экран календаря; общий сервис записи для голоса, Telegram/MAX и кабинета; поиск по доверенному номеру или ID отправителя; запрет выбора произвольной встречи; внутренний календарь без обязательного внешнего подключения. Совместимость со старыми записями сохранена через импорт из `tenant.settings` и временное зеркало.

Не объявлять весь сценарий готовым до: внешнего update/delete, письма с настоящим вложением, проверки привязки контакта между каналами и живого сквозного теста с аккаунтами компании.
