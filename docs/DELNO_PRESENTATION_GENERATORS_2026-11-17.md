# Генерация презентаций для DELNO: открытые инструменты

Проверено 17.11.2026. Цель: Hermes по просьбе компании создаёт презентацию, сохраняет PPTX и PDF в её файловом пространстве и при необходимости прикладывает выбранный файл к письму. Формат и вложение выбирает пользователь; наличие почты и внешнего календаря не является условием генерации.

Нужна отдельная проверка tenant isolation, авторизации API, хранения файлов и нагрузки до интеграции. Закрытая [ошибка безопасности](https://github.com/presenton/presenton/issues/972) касалась desktop-сборки; это не доказывает изоляцию многопользовательского Docker-развёртывания. |

## Предлагаемая схема

1. Hermes собирает цель, аудиторию, исходные данные, желаемый объём и формат; предлагает подготовить презентацию, только если это уместно. Может использовать материалы компании из её базы знаний и выбранных файлов.
2. Задача генерации получает `tenant_id`, `run_id`, разрешённые `file_id`; содержимое не передаётся между компаниями. Рендерер запускается в изолированном job-контейнере без доступа к чужим файлам и секретам.
3. Первая версия: Hermes составляет структурированный Markdown, Marp CLI выдаёт PDF и PPTX; для редактируемых фирменных слайдов отдельный путь на PptxGenJS. Оба формата сохраняются как файлы компании. Presenton оценить на отдельном стенде.
4. Для отправки почты Hermes указывает конкретный `attachment_id`; модуль почты заново проверяет принадлежность файла компании. Правило вложения у сценария: «спросить», «прикладывать этот файл», «не прикладывать»; по умолчанию — спросить.
5. Приёмка: две компании параллельно генерируют и отправляют файлы; ни одна не видит темы, исходники, результаты и ссылки другой. Проверить PDF/PPTX визуально, русские шрифты, лимиты размера, отмену задания, ошибки и сроки хранения.

Открытый код бесплатен, но генерация моделью, изображения и серверные ресурсы могут стоить денег. Генератор сейчас исследован, а не установлен в DELNO; обещать пользователям готовую функцию пока рано.

## Работа с таблицами и раздел «Файлы»

В меню кабинета добавлен отдельный раздел «Файлы»; загрузка перенесена туда из календаря. Папки, скачивание, перемещение и удаление реализованы в ветке через tenant-scoped API. Hermes может перечислять файлы и папки, создавать текстовые файлы, читать небольшие текстовые файлы, перемещать и удалять файлы, создавать и удалять пустые папки. Содержимое XLSX/DOCX/PDF/PPTX он пока не обрабатывает через этот раздел.

Целевой набор инструментов Hermes: `files.list`, `files.read`, `files.create`, `files.update`, `files.delete`, `tables.inspect`, `tables.read_range`, `tables.create`, `tables.update_range`, `tables.add_sheet`, `tables.delete_sheet`, `tables.export_pdf`. Все операции получают `file_id`, проверяют `tenant_id`, права и версию файла; изменения записывают новой версией с возможностью отката. Удаление файла и изменение диапазона требуют явного подтверждения пользователя.

Для XLSX использовать библиотеку работы с ячейками (например, openpyxl), для CSV — стандартный модуль Python. LibreOffice Calc использовать как отдельный конвертер/рендерер XLSX, ODS и PDF и для сложных функций, которые библиотека не поддержит. Не давать модели прямой доступ к файловой системе или запуск произвольных макросов. Бинарные файлы обрабатывать в изолированном job-контейнере с лимитами памяти, времени и размера.

## Документы и письма

Раздел «Файлы» должен хранить также текстовые документы, коммерческие предложения, письма, договорные черновики и отчёты. Hermes составляет содержание и предлагает формат. Сначала черновик показывается в чате; после подтверждения пользователь получает редактируемый DOCX (или TXT/Markdown по запросу) и, если нужно, PDF из того же источника. Для DOCX использовать локальную библиотеку генерации документов и шаблоны компании; LibreOffice Writer запускать в отдельной задаче для конвертации DOCX → PDF. Исходящий email может содержать текст письма без вложения либо выбранный готовый файл по `file_id`.

Нужны отдельные инструменты `documents.create`, `documents.read`, `documents.revise`, `documents.export_pdf` и общие операции файлов: список, загрузка, скачивание, версии, удаление. Имена и содержимое файлов всегда из пространства компании. Изменение существующего файла сохраняет новую версию; отправка письма и удаление требуют явного подтверждения. Это целевая схема, а не объявление уже работающих инструментов.
