# Серия блога DELNO: ИИ в бизнесе + дешёвый функциональный сотрудник

**Ревизия:** 2026-10-09  
**Объём:** ~36 статей (волна 1) + бэклог до 50  
**Продукт в текстах:** только **DELNO** — ИИ-сотрудник 24/7: сайт (чат + голос), Telegram, MAX, почта, телефон (тариф «Диалоги + звонки»), одна база знаний, запись клиентов, эскалация человеку.  
**Цена-якорь в CTA:** от **2 990 ₽/мес** (диалоги) / **5 990 ₽** (+звонки) — без «бесплатного чуда», с честной границей «что умеет / что отдаёт человеку».

### Главный месседж для малого бизнеса (сквозь всю серию)

Каждый владелец салона, сервиса, студии должен уйти со статьи с ощущением:

| | Обещание | Как доказываем в тексте |
|---|----------|-------------------------|
| **Просто** | Не нужен IT-отдел и «проект на полгода» | Старт с **одной задачи** и **одного канала**; материалы — то, что уже есть (сайт, прайс, правила) |
| **Быстро** | Первый сценарий — **за несколько дней**, не месяцев | Демо на сайте → заявка → база знаний → проверка диалогов → включение |
| **Недорого** | От **2 990 ₽/мес** — заметно дешевле ставки администратора | Считаем «часы на трубке / неявки / потерянные записи» vs подписка; без скрытого «внедрение от 500 тыс.» |

**Анти-страх в каждом тексте:** без корпоративного GenAI-пафоса, без «цифровой трансформации». Язык предпринимателя: «пока вы у клиента — DELNO отвечает и ведёт запись».

**Публичный запрет:** во всех статьях, meta, CTA и SEO-материалах **не упоминать AVA**, внутренние сервисы office, Asterisk и прочую внутрянку. Снаружи — только бренд **DELNO** / dlno.ru.

## Жизненный цикл клиента (что автоматизировать в первую очередь)

Не обрываем цепочку на «записал». Ниже — сценарии, которые **реально тревожат** малого предпринимателя: жрут время администратора / хозяина и с радостью отдаются на автомат. Приоритет = боль × частота × готовность отдать ИИ.

| # | Сценарий | Боль владельца (время/деньги) | Готовность автоматизировать | Старт в DELNO |
|---|----------|-------------------------------|-----------------------------|---------------|
| 1 | **Ответ на «сколько стоит / есть ли окно?»** 24/7 | Чаты и звонки в час пик, пока мастер занят; клиент уходит к конкуренту | Очень высокая | Сайт / TG / MAX / телефон |
| 2 | **Запись** в слот | Ручной подбор времени, ошибки, двойные записи | Очень высокая | + календарь |
| 3 | **Перенос / отмена** самим клиентом | Админ снова в переписке; слот «висит» занятым | Очень высокая | Тот же диалог |
| 4 | **Подтверждение накануне** напрямую у человека | Ручной обзвон часами; неявки 15–25% слотов впустую | Очень высокая | Исходящее в мессенджер / звонок по тарифу |
| 5 | **Короткое напоминание в день визита** (за 2–3 ч) | «Забыл / застрял» в последний момент | Высокая | Тот же канал |

### Цепочка «ядро» (всегда в статьях столпа C)

```
спрос → запись → перенос/отмена → подтверждение накануне → (напоминание в день)
      → визит → «как прошло?» / следующая запись → (отзыв)
```

Рядом по желанию владельца: лист ожидания, FAQ, возврат «давно не были».

### Что сознательно не толкаем в первую волну автоматизации

Массовый спам-обзвон, «жёсткие» продажи, медсоветы, спорные скидки без человека — это либо вред бренду, либо зона эскалации. В текстах честно говорим: **DELNO закрывает рутину первой линии**, спорное — человеку.
