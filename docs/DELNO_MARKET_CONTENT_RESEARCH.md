# Исследование рынка: контент и позиционирование DELNO

**Дата:** 2026-10-09  
**Цель:** глубина для SEO-серии блога — не «набросок из 12 сценариев», а карта рынка, конкурентов, болей SMB, ценовых якорей и пробелов в контенте.  
**Публичный бренд:** только DELNO (внутрянка не в тексты).

Источники: Naumen / РБК Компании, JSON.TV, ComNews, TextBack; продуктовые и блог-страницы Syntera24, FlowBots, Jivo×YCLIENTS, «Запиши» (724bot), Big Russian Bot, BotKraft, Neurobot, SuperIntellect, NeiroStaff, Скорозвон, МТС/МегаФон voice; SEO-гайды по автосервисам и бьюти-кейсы (salistica, isalon, vc.ru).

## 1. Рынок (цифры и смысл для DELNO)

| Сигнал | Оценка | Что значит для нас |
|--------|--------|-------------------|
| Диалоговый ИИ РФ (Naumen) | ~8 млрд ₽ (2024), ~+30–34% YoY → ~11 млрд в 2025 | Категория растёт; внимание рынка есть |
| Голос + чат-боты для бизнеса (JSON.TV) | >10 млрд ₽, +30% в 2025; много спроса в «под ключ» вне SaaS | SMB часто платит студиям 70–180 тыс. разово — наше преимущество: подписка от 2 990 |
| Сдвиг к агентам (ComNews) | Не «чат», а действия: запись, CRM, эскалация | Контент про **сотрудника**, не про кнопки |
| Исходящие обзвоны дорожают / регулируются | Бизнес уходит в чаты и push | Подтверждение накануне в **мессенджере** — правильный акцент vs «робот-обзвон» |
| Нишевание (JSON.TV) | В чат-ботах выигрывают либо гиганты с моделями, либо **узкие сценарии** | DELNO = SMB + запись/первая линия + мультиканал, не «ещё одна GPT-обёртка» |

**Вывод:** рынок перегрет обещаниями «ИИ-агентов» и дорогим custom. Окно для DELNO — **малый сервисный бизнес**, которому страшно и дорого «внедрять ИИ», но больно терять заявки из мессенджеров и слоты из-за неявок.

## 2. Карта конкурентов (релевантные DELNO)

### 2.1. SaaS / подписка под запись (бьюти и услуги)

| Игрок | Каналы | Запись | Голос PSTN | Цена (ориентир) | Контент-угол |
|-------|--------|--------|------------|-----------------|--------------|
| **Jivo ИИ × YCLIENTS** | TG, WA, VK, сайт… | Да, слоты YCLIENTS | Нет | ~3 990 ₽/мес, 7 дней free | «подключи к журналу за час» |
| **FlowBots** | TG, MAX + YCLIENTS | Да + реактивация + отзывы | Нет | 19 900 подкл. + 5 900/мес | салон/мастер, единый тариф |
| **Запиши (724bot)** | TG, VK, MAX, Авито (+WA) | YCLIENTS / DIKIDI | Нет | **2 990 ₽/мес**, 7 дней free | «не меняйте журнал» |
| **Syntera24** | TG, WA, VK, MAX, Авито, сайт | Запись / заявка → CRM | **Нет (явно)** | не витрина как у beauty-SaaS | AI-админ, «не терять заявки» |
| Custom-студии (BRB, BotKraft…) | под заказ | YCLIENTS и др. | редко | 30–200 тыс. разово + сроки недели | кейсы сетей, ROI no-show |

### 2.2. «Нейросотрудник» / агент-платформы (шире, дороже)

Neuro42, NeuroOffice, Raiseach, Cloud.ru workflows — упор на CRM/1С/внутренние процессы, чеки часто **от 15–50 тыс./мес** или enterprise. Для парикмахера/шиномонтажа — overkill; в контенте DELNO отстраиваться: **не платформа на 100 агентов, а один сотрудник первой линии**.

### 2.3. Голос на телефоне

| Игрок | Ориентир цены | Заметка |
|-------|---------------|---------|
| НеоStaff и аналоги «нейросотрудник на линии» | от ~20–60 тыс. вход + минуты | Прямой конкурент по языку «сотрудник» |
| Скорозвон AI на входящих | от **90 000 ₽/мес** / пакеты минут | Не для микробизнеса |
| МТС / МегаФон voice | копейки–рубли за минуту / пакеты | Операторы; слабый «ИИ по вашей базе» в SMB-нарративе |

**Ценовой зазор DELNO:**  
- Текст+виджет+мессенджеры от **2 990** — в одной полке с «Запиши»/Jivo, но с **голосом на сайте** и опцией **телефона** в тарифе 5 990.  
- Полный voice-PSTN у конкурентов часто на порядок дороже → в статьях честно: «начните с мессенджеров и виджета; звонки — когда поток уже есть».

### 2.4. Где конкуренты сильны / слабы (для контента)

| Сила конкурентов | Слабость / наш клин |
|------------------|---------------------|
| Глубокая связка с **YCLIENTS** | DELNO пока продаёт сценарий; контент не врать про «из коробки YCLIENTS», обещать запись/подтверждение по правилам + путь интеграции |
| Куча нишевых лендингов «бот для автосервиса/салона» | У нас мало посадочных/статей — **догнать серией C** |
| Кейсы «no-show с 18% до 5%» | Повторить формат с цифрами-якорями рынка + демо DELNO |
| Только текст **или** только голос | **Мультиканал + одна база** (сайт/TG/MAX/почта/телефон) — редкий честный оффер для SMB |

## 3. Боли предпринимателя ( empirically из рынка)

Сводка из блогов Syntera, salistica, isalon, BotKraft, кейсов СТО:

| Боль | Типичные цифры/формулировки рынка | Приоритет автоматизации |
|------|-----------------------------------|-------------------------|
| Не успевают отвечать в мессенджерах в пик / вечером / в выходные | «10–15 мин без ответа → ушёл к другому»; «30–50% входящих теряется в пик» | ★★★★★ |
| Заявки размазаны по TG / WA / VK / Авито / Instagram | Нет единого окна, статусов, «кто не ответил» | ★★★★★ |
| Ручная запись → ошибки | до ~12% ошибочных записей (время, мастер) | ★★★★★ |
| Неявки | 15–22% слотов; обзвон накануне 0,5–2,5 ч/день | ★★★★★ |
| Админ у стойки vs переписка | 60–70% времени на рутину записи | ★★★★★ |
| Нет повторных визитов / «уснувшая» база | реактивация 8–15% без рекламы (кейсы ботов) | ★★★★ |
| Телефон занят / недозвон | каждый 5-й звонок без ответа в пик (СТО) | ★★★★ (если есть поток звонков) |
| Страх «ИИ выдумает / накосячит» | почти в каждом FAQ конкурентов | ★★★★ (эскалация в каждом тексте) |
| Дорого / долго внедрять | custom 2–6 недель, 70–180 тыс. | ★★★★★ (наш месседж просто/быстро/недорого) |

**Эмоциональный язык владельца (использовать в статьях):**  
«пока я у клиента — чат горит», «слот пустой — деньги в ноль», «опять обзванивать завтрашних», «написала в три канала — никто не собрал», «боюсь робота, но админ не резиновый».

## 4. Что уже читают (форматы-победители)

Повторяющиеся форматы у игроков с трафиком:

1. **Потерянные заявки из мессенджеров** (салон/клиника) — почти у всех AI-админов.  
2. **No-show / напоминания с кнопками подтвердить-перенести** — цифры до/после.  
3. **Пошаговое внедрение чат-бота** без IT.  
4. **Нишевые лендинги+статьи:** салон, барбер, клиника, автосервис, фитнес.  
5. **Сравнение:** кнопки vs ИИ; админ vs бот; конструктор vs готовый.  
6. **YCLIENTS/DIKIDI как якорь** — «не ломаем ваш журнал».  
7. **Кейсы с деньгами** (оборот, % неявок, окупаемость).  
8. SEO у локального сервиса: услуги × гео × симптомы (авто) — для DELNO это **B2B-контент «как сервису не терять запись»**, не локальное SEO чужого СТО.

**Пробелы рынка (куда бить DELNO):**

| Пробел | Идея контента |
|--------|----------------|
| Мало честных текстов «**голосом на сайте до телефонии**» | B02, связка с дешёвым стартом |
| MAX рядом с Telegram для SMB | B04 (конкуренты пишут, но слабо объясняют «зачем») |
| Почта как канал первой линии | B05 |
| **Один сотрудник** на текст+голос+телефон vs зоопарк ботов | A01, B08, E02 |
| «Под ключ 150 тыс.» vs **2 990** — калькулятор для владельца | E01, A03 |
| Универсальный цикл **после** подтверждения: лист ожидания, rebook, отзыв | C12 + отдельные статьи F-серии |
| Анти-хайп: где ИИ **не** нужен малому бизнесу | A05, A08 — повышает доверие |
