# DELNO — ключи LLM и монетизация токенов

**Revision:** 2026-11-12 · Cloud4Box

## Голос (уже было в архиве)

| Параметр | Значение |
|----------|----------|
| Realtime model | `gpt-realtime-2.1-mini` |
| Realtime voice | `cedar` |
| Site/cabinet TTS | `DELNO_TTS_VOICE=cedar` (`gpt-4o-mini-tts`) |
| AVA phone path | `openai_realtime` в `ai-agent.local.yaml` |

Гермес может сменить пресет голоса («смени голос на cedar») → `tenant_voice_profiles`.

## Две модели ключей

### A) Platform keys (рекомендация для старта / тарифа «под ключ»)

- DELNO держит **один** OpenAI ключ (egress через proxy).
- Клиент платит **подписку** (Диалоги / Диалоги+звонки) + при необходимости **пакет минут/токенов**.
- Списание уже заложено в `billing`: `token_credits`, `llm_*_per_1k`, `call_minute`.
- Плюсы: простой онбординг, единый Realtime, контроль качества, маржа на токене.
- Минусы: вы несёте vendor risk и abuse; нужен hard cap per tenant.

### B) BYOK (клиент вставляет свой ChatGPT/OpenAI ключ)

- Ключ в tenant vault (`kind=openai` — следующий шаг), Hermes принимает через безопасную форму.
- Подписка = кабинет + каналы + телефония; **токены клиент платит OpenAI сам**.
- Плюсы: нет себестоимости LLM у вас; enterprise-friendly.
- Минусы: сложнее саппорт (битые ключи, лимиты), нельзя гарантировать Realtime 2.1 на всех аккаунтах, утечки ключей в support.

## Практичная схема для DELNO

1. **По умолчанию — Platform keys** на тарифе с включённым пакетом токенов/минут.
2. **BYOK опционально** для тарифа «свой ключ» (скидка на подписку, без token markup).
3. Деньги брать за:
   - подписку каналов/кабинета;
   - сверхпакет минут звонков;
   - сверхпакет LLM/TTS (только в режиме Platform);
   - разовые услуги (подключение Mango, миграция KB) — вне подписки.

Не продавать «голые токены OpenAI» без подписки — иначе вы становитесь реселлером API с тонкой маржой и всеми рисками.
