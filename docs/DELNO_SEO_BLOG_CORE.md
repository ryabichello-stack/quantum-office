Пока частоты `wsBase` в коде = `null`. Структура ядра и привязка к статьям **готовы** — после одобрения API или ручной выгрузки из [wordstat.yandex.ru](https://wordstat.yandex.ru/) заполняем числа и переранжируем.

### Что сделать в Директе (один раз)

1. Войти в [Директ](https://direct.yandex.ru/) под тем же логином, что OAuth.  
2. Завершить **регистрацию приложения / доступ к API** (та же заявка, что для Wordstat API).  
3. ClientId: `279b496a594b4717adcecd7174237592`.  
4. После одобрения — новый verification code → обмен на mailer → `GET /yandex/wordstat/phrases`.
