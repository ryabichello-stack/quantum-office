# Graphics Pipeline

## Decision order

1. Can CSS/SVG/lucide solve it? → prefer that
2. Product screenshot or real UI mock → prefer credibility
3. Cursor **GenerateImage** → only when role is clear (hero illustration, social OG)
4. **threejs** → only if 3D materially explains product (rare)

## Roles

| Role | Medium |
|------|--------|
| Explain product | Console mock, widget demo, short video |
| Trust | Real limits, logos (when available), human contact |
| Emotion | Restrained photography/illustration |
| Decoration | Avoid |

## Workflow

Generate or export → place in layout → **run app** → screenshot → critique composition → iterate.

Never approve an asset viewed only in isolation.
