# Apple Premium Web (extracted principles)

## Extract (do not clone brands)

| Source | Extract |
|--------|---------|
| Apple | Physical motion, interruptible transitions, clear feedback, reduced motion |
| Linear | Typographic discipline, tight vertical rhythm, minimal chrome |
| Stripe | Confident whitespace, precise borders, credible product visuals |
| Vercel | Dark/light surface clarity, developer-trust typography |

## Pair with

- `apple-design`, `emil-design-eng`, `mobile-native`, `animate`

## Anti-patterns

- Purple SaaS gradient hero by default
- Glassmorphism stacks
- Decorative 3D unless `threejs` skill explicitly justified

## DELNO-specific

- Yellow accent `--y` / v4 mint accent on convert pages — pick one system per page, do not mix arbitrarily.
- Voice orb is a **product** visual, not wallpaper.
