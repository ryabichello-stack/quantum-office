# Каналы связи и контакты DELNO

DELNO отвечает там, где клиенту удобно: на сайте, по телефону, в мессенджерах и по почте.

## Как связаться с DELNO (демо и заявки)

| Канал | Контакт |
|-------|---------|
| **Сайт** | [dlno.ru](https://dlno.ru) — чат и голосовой виджет на странице |
| **Телефон** | **8 800 555-00-00** (бесплатный номер для демо и заявок) |
| **Telegram** | [@Dlno_bot](https://t.me/Dlno_bot) |
| **MAX** | [Чат с ботом DELNO в MAX](https://max.ru/@id471405233378_bot) |
| **Почта** | **office@dlno.ru** |

Ответим в рабочее время. На сайте демо-помощник доступен круглосуточно.

## Какие каналы подключает DELNO для бизнеса

- **Сайт** — чат, голосовой виджет или единый кристаллический виджет
- **Telegram** — бот, принадлежащий клиенту (branded connect)
- **MAX** — бот клиента через MAX API
- **Почта** — разбор входящих и согласованные цепочки
- **Телефон** — входящие и исходящие (тариф «Диалоги + звонки», Mango Office / SIP)

## Какие мессенджеры можно подключить?

В первую очередь — **Telegram** и **MAX**. Другие мессенджеры подключаем, если у канала есть подходящий API или бот-интерфейс. История клиента и база знаний остаются общими для всех каналов.
