# Как заполнить знания о компании

1. Скачайте шаблон **Профиль компании** в кабинете → Знания.
2. Заполните своими данными (или надиктуйте Hermes).
3. Загрузите файл обратно в Знания **или** скажите Hermes: «сохрани профиль компании».
4. Для телефонии скачайте **Сценарий секретаря**, заполните или скажите: «предложи сценарий из базы знаний».
5. Hermes сохранит сценарий, включит выбранные tools и применит их к линии.

Не вставляйте пароли SIP/почты в эти файлы — для секретов есть безопасная форма в Hermes.
