# CRM, скрипт и воронка внутри DELNO

Внутри DELNO — не только ответы снаружи:

- **Внутренний CRM с клиентами** — обращения и контакты в одном месте;
- **Работа по скрипту** — сценарий первой линии: что спрашивать, как записывать, когда передавать человеку;
- **Настраиваемая воронка продаж** — статусы лида/сделки под ваш процесс (заявка → квалификация → запись/счёт → закрытие);
- дальше: задачи, напоминания, отчёты по каналам и конверсии — наращиваем под задачу.

**Формулировка:**
«DELNO — не только ответы в чате. Внутри — кабинет с клиентами и заявками, скрипт секретаря и воронка продаж. Снаружи — сайт, мессенджеры, почта, календарь, файлы и телефония из одной базы знаний.»
