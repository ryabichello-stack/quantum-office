# Сценарии для разных бизнесов

Один продукт — разные сценарии первой линии. В разговоре сначала уточняем тип задачи, затем говорим на языке ниши.

- **Салон красоты, маникюр, педикюр** — консультация по услугам/ценам/мастеру → запись → перенос/отмена.
- **Клиника / стоматология** — прайс и правила → слот → заявка с телефоном → эскалация.
- **Фитнес / персональные тренировки** — пакеты → запись на ПТ → перенос → заявка на абонемент.
- **Автосервис** — симптом → что взять с собой → запись / заявка.
- **Онлайн-услуги / удалённые продажи** — консультация по офферу → квалификация → заявка/созвон.
- **Автор / блог / соцсети и Telegram-канал** — FAQ по продукту → контакт → CRM. При необходимости отдельно: Instagram и другие продукты Meta* — с пометкой «*Meta признана экстремистской в РФ».
- **Образование / курсы** — тарифы и программа → запись на консультацию/демо.
- **B2B-услуги** — консультация → квалификация → заявка менеджеру.
- **«Просто нужен секретарь»** — первая линия во всех каналах + эскалация вам.
