# Экспорт DELNO

В архиве находится полный исходный код опубликованной версии №23 сайта DELNO
(коммит `07ef5336bad26eea22930318be4dc7307530cf2f`). Включены страницы, стили,
изображения, API-маршруты формы заявок и голосовой демонстрации.

## Быстрый запуск на компьютере

Требуется Node.js 22 или новее.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Развёртывание на собственном VPS

Самый простой воспроизводимый вариант — Docker:

```bash
docker build -t delno-site .
docker run -d \
  --name delno-site \
  --restart unless-stopped \
  -p 3000:3000 \
  --env-file .env.production \
  delno-site
```

Направьте Nginx или Caddy с домена на `http://127.0.0.1:3000` и подключите SSL.

Без Docker:

```bash
npm ci
npm run build:node
npm run start:node
```

Для постоянной работы процесса используйте systemd или PM2.

## Переменные окружения

Скопируйте `.env.example` в `.env.production` и заполните нужные значения:

- `OPENAI_API_KEY` — озвучивание ответов в голосовом демо;
- `LEAD_WEBHOOK_URL` — адрес, куда отправлять заявки;
- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — альтернативная доставка заявок в Telegram.

Секретные значения намеренно не включены в архив. Если не указать ключ OpenAI,
остальной сайт продолжит работать, но голосовое озвучивание будет отключено.

## Важно

- Каталог `.openai` сохранён как техническая информация исходного проекта, но
  для собственного хостинга он не требуется.
- Cloudflare/Sites-заготовки в `worker/`, `db/`, `build/` и `examples/`
  сохранены в архиве, но исключены из проверки типов обычной Node.js-сборки.
- Основная страница находится в `app/page.tsx`, стили — в `app/globals.css`,
  изображения — в `public/`.
- Перед переносом домена сначала проверьте сайт на временном поддомене, затем
  измените DNS-записи. Текущую публикацию в Sites можно оставить работающей до
  завершения проверки.
