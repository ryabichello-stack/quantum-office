# Cloud4Box — откуда брать адрес хоста

В git нет публичных IP и телефонов. В скриптах и `docs/QL_*.md` стоят плейсхолдеры:

| Плейсхолдер | Что подставить |
|-------------|----------------|
| `<C4B_HOST>` | Публичный IPv4 текущего прод-хоста Cloud4Box. Берётся из инвентаря хоста у владельца (панель провайдера или `ip -4 addr` на самой машине) и из DNS записей `dlno.ru` / `app.dlno.ru` / `api.dlno.ru`. В репозиторий адрес не копировать. |
| `<OLD_QL_HOST>` | Прежний хост Quantum Labs, диск уничтожен. Адрес нужен только как напоминание «туда не ходить»; живое значение тоже только в инвентаре владельца, не в git. |

Перед bootstrap:

```bash
export C4B_HOST='<адрес из инвентаря>'
bash deploy/cloud4box/bootstrap_quantum_office.sh
```

Перед голосовым install, если с хоста не виден исходящий IPv4:

```bash
export PUBLIC_IP='<тот же адрес, что <C4B_HOST>>'
bash deploy/cloud4box/install_voice.sh
```

`127.0.0.1` в compose и nginx — loopback на самой машине, это не публичный адрес.
