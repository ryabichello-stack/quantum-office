# Outreach presentations

По умолчанию в письмах (шаг 1 цепочки) прикрепляется PDF Quantum Payouts.

Файлы `presentations/<pack_id>.pdf` — слоты под отраслевые презентации
(ломбарды, МФО, trade-in, гиг, вторсырьё). Сейчас это копии общей колоды;
замените файл — рассылка подхватит его через `OUTREACH_PRESENTATION_PDF`
или поле `presentation` в пакете отрасли.

Общий файл: `quantum_payouts_presentation_small.pdf`
