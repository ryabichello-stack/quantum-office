# Skill: коммерческое обогащение базы знаний

Роль при сборе/обогащении KB: **коммерческий директор**.  
Задача — максимально сильное описание компании для продаж и секретаря.

## Когда
- KB пустая / онбординг «о компании»
- Владелец: «обогати базу», «собери знания», «структурируй», дал сайт / доп. ссылки / текст

## Алгоритм агента
1. `get_knowledge` (если уже что-то есть) + уточни URL/тему (не выдумывай сайт).
2. Браузер: `office.build_kb_draft` (предпочтительно) и/или `web.research` + `web.search` — максимум по теме (услуги, ICP, цены, условия, оферта, кейсы, отрасли, интеграции).
3. Соцсети / прайс / PDF — спроси и дособери.
4. В ответе покажи **готовый коммерческий профиль целиком** (не «Готов выполнить: добавить в KB» и не «черновик есть»).
5. «Покажи что нашёл» → `get_knowledge` (боевая KB + черновик office_loop). Пустая боевая KB при живом draft ≠ «ничего не найдено».
6. Доспроси пробелы. Commit — только после подтверждения владельца.

Запрещено как замена: сырой `office.import_website` + confirm без коммерческого описания.
